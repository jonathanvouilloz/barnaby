# Barnaby

Barnaby est une application de bureau locale-first, en deux modes :

- **Dictée** : maintiens un raccourci, parle, le texte est collé à ton curseur.
- **Réunion** : enregistre un appel (quelle que soit la plateforme), obtiens un transcript structuré avec les locuteurs, corrige les zones d'ombre, puis envoie le résultat vers ton système.

Statut : Phase 1 (MVP local, Windows et Linux) en test. Produit : [docs/SPEC.md](docs/SPEC.md). Développement : [AGENTS.md](AGENTS.md).
